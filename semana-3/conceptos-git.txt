Repositorio: Es un entorno de almacenamiento diseñado para proyectos de software que opera tanto de forma local (tu equipo) como remota (la nube). Su función principal es registrar detalladamente cada modificación, permitiendo documentar el progreso y recuperar estados funcionales tras errores o malas manipulaciones. Para ello, utiliza el comando commit como punto de guardado y los comandos (reset o checkout) para la restauración. Además, facilita la colaboración simultánea, permitiendo que varios desarrolladores integren sus cambios para potenciar el trabajo en equipo.

Commit: Es una forma de crear un punto de guardado en un proyecto, ya sea de forma local o remota, generando un respaldo de cada actualización para evitar daños por errores internos o externos. El commit es el guardado local y el push es el guardado remoto. El commit te permite guardar tu progreso mientras trabajas, ofreciendo una forma segura de avanzar sin errores, ya que puedes modificar y experimentar sin miedo gracias a que siempre tienes ese punto de retorno garantizado. 

Push: Es el comando que transfiere tus cambios locales hacia el repositorio remoto en GitHub. Funciona como un respaldo externo y una herramienta de colaboración, ya que permite que otros desarrolladores visualicen, descarguen y contribuyan al proyecto de forma sincronizada.
