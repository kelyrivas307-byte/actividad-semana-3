Qué hace esta ruta:
Una ruta identifica la acción del usuario y ejecuta el código necesario para mostrar la página web. Esto permite que, al conectar la terminal con el navegador mediante una dirección como http://localhost:3000, podamos revisar que todo esté funcionando correctamente o realizar las modificaciones que necesitemos".
